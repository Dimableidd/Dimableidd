## 👨‍💻 About Me

I'm a **game developer and game AI researcher** focused on gameplay programming, game mechanics, and game-system architecture. I work primarily with Unity and C#, and I'm interested in applying machine learning methods to game AI.

I completed my Master's degree at **ITMO University** in Mathematical and Computer Modeling. My thesis explored **reinforcement learning for the automatic generation of Hierarchical Task Networks (HTNs)**. I continue to work on game development projects and research in game AI.

## 🎮 Featured Projects

### [Free Glassing](https://freeglassing.tilda.ws/)
**Unity · Game Development · Android / iOS / Windows**

A game project for which I worked as a Unity Developer, contributing to game architecture, gameplay mechanics and systems, prototyping, UI/UX, analytics, technical documentation, testing, and builds for multiple platforms.

### Grim Waves
**Unity · Gameplay Programming · Game AI**

Worked as a Unity Developer on the game demo, including game architecture, gameplay mechanics and systems, prototyping, technical documentation, testing, bug fixing, and game AI.

- [View the project portfolio](https://disk.yandex.ru/d/BhqQ3Kbjnelq9Q)

### [Automatic HTN Generation](https://github.com/Dimableidd/Automatic_HTN_generation)
**Game AI · Reinforcement Learning · HTN**

Research project exploring the automatic generation of Hierarchical Task Networks (HTNs) for game AI using reinforcement learning.

The project investigates how behavior demonstrated by a reinforcement-learning agent can be analyzed and used to generate a hierarchical representation of game-agent behavior.
